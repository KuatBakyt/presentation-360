# Auto Explore — презентация автомобиля 360°

Демонстрационный сайт: вращение кузова, просмотр условного салона, смена цвета и интерактивные точки.

## Запуск

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Сборка и установка пакетов не нужны. Для Vercel: Framework Preset — Other, корневая папка — корень репозитория, без команды сборки.

Модель автомобиля и салон схематичные, не соответствуют конкретной марке. Для клиентского проекта замените их точной 3D-моделью или панорамными фотографиями.

Three.js r170 хранится локально в assets/three.js; лицензия — assets/THREE-LICENSE.txt.
